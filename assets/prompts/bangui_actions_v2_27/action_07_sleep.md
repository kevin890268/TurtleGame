# Action 07 — SLEEP
# 睡覺 / Sleep

ACTION_ID:
10

ACTION_NAME:
sleep

DESCRIPTION:
The turtle peacefully falls asleep. Eyes close gradually and the body becomes still. Do not draw ZZZ symbols.

==================================================
1. ANIMATION GOAL
==================================================

Create ONE continuous four-frame animation sequence.

Frame sequence:

F1 → F2 → F3 → F4

For looping actions, Frame 4 must transition naturally
back to Frame 1.

For one-shot actions, Frame 4 may represent the completed state.

The four frames must clearly belong to the SAME movement.

==================================================
2. FRAME SEQUENCE
==================================================

FRAME 1:
Awake but relaxed, eyes open softly.

FRAME 2:
Eyes begin closing; head settles slightly.

FRAME 3:
Eyes fully closed; peaceful sleeping posture.

FRAME 4:
Subtle breathing/settled pose, ready to loop.

==================================================
3. ANATOMY AND MOTION
==================================================

The movement must remain anatomically believable
for the SAME young Chinese three-striped box turtle.

The shell remains rigid.

Do NOT squash, stretch or morph the shell.

Do NOT add or remove limbs.

Do NOT duplicate body parts.

Do NOT create impossible joints.

Movement must come from believable turtle anatomy.

Do NOT use motion blur.

Do NOT use speed lines.

Do NOT exaggerate the character into a chibi or cartoon deformation.

==================================================
4. FOUR VIEW CONSISTENCY
==================================================

Apply the SAME physical action to all four views:

F = Front 3/4
R = Right 3/4
B = Back 3/4
L = Left 3/4

The four rows are different views of ONE physical turtle.

Do not make each row perform a different action.

Do not redesign the turtle between views.

Preserve the character_reference.png identity and all rules
defined in rules.md.

==================================================
5. SPECIAL ACTION RESTRICTIONS
==================================================

The sprite sheet contains ONLY the turtle.

Do NOT add props or environmental objects.

For EAT:

vegetables or crumbs.

plants or underwater scenery.
