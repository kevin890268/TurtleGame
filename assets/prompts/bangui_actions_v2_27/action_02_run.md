# Action 02 — RUN
# 快速爬行 / Fast Crawling

ACTION_ID:
03

ACTION_NAME:
run

DESCRIPTION:
The turtle performs a noticeably faster locomotion cycle.

This is the turtle's fastest terrestrial movement
in the basic movement set.

It must still look like a turtle.

This is NOT mammal running.

This is NOT a dog-like gait.

This is NOT jumping.

==================================================
1. ANIMATION GOAL
==================================================

Create ONE continuous four-frame fast crawling cycle.

Frame sequence:

F1 → F2 → F3 → F4 → F1

The movement should clearly be faster than WALK_A
and WALK_B.

The turtle remains close to the ground.

==================================================
2. FRAME 1 — START
==================================================

The turtle begins a quick forward movement.

Head is slightly extended.

Front legs are preparing for a stronger step.

Rear legs are positioned for propulsion.

The shell remains rigid.

==================================================
3. FRAME 2 — STRONG STEP
==================================================

The turtle pushes forward more strongly.

One front leg reaches forward.

The opposite rear leg extends backward
to provide propulsion.

The body shifts forward.

The shell remains stable.

==================================================
4. FRAME 3 — OPPOSITE STRONG STEP
==================================================

The opposite pair of legs performs the next
strong movement.

The turtle reaches the strongest forward
locomotion phase.

Leg positions must be clearly different
from Frame 2.

The body moves forward naturally.

The shell remains rigid.

==================================================
5. FRAME 4 — TRANSITION
==================================================

The turtle prepares for the next cycle.

Leg positions return toward the starting
configuration.

The turtle remains in a fast locomotion posture.

Frame 4 must transition naturally into Frame 1.

==================================================
6. RUNNING MECHANICS
==================================================

The turtle may move its legs faster and with
slightly larger movement than WALK_A.

However:

- shell remains rigid
- body proportions remain unchanged
- head remains anatomically attached
- legs remain anatomically attached
- no exaggerated squash and stretch
- no floating
- no jumping
- no mammal running posture

Do NOT use motion blur.

Do NOT use speed lines.

The sense of speed must come entirely from
the turtle's body and leg positions.

==================================================
7. FOUR VIEW CONSISTENCY
==================================================

Apply the same physical fast crawling movement to:

F = Front 3/4
R = Right 3/4
B = Back 3/4
L = Left 3/4

All four views depict the same individual turtle.

==================================================
8. SPRITE SHEET
==================================================

Create exactly ONE 4 × 4 sprite sheet.

Columns:
Frame 1 | Frame 2 | Frame 3 | Frame 4

Rows:
F
R
B
L

The labels above are INTERNAL ORGANIZATION ONLY.
DO NOT DRAW THEM.

Exactly 16 cells.

==================================================
9. BACKGROUND
==================================================

Pure solid chroma-key magenta.

RGB 255, 0, 255.

No environment.
No floor.
No water.
No props.
No particles.
No text.
No effects.

==================================================
10. FINAL REQUIREMENT
==================================================

The final sheet must show ONE EXACT SAME turtle
performing a fast but anatomically believable
terrestrial crawling cycle.

The turtle must remain visually identical to
character_reference.png and all rules in rules.md.
