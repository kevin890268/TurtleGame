# 戶外池場景圖

戶外池已經改成「挖在草地裡的池塘」：正面是土層剖面，池子是剖面上的一扇窗，四周一圈全景。
程式已經先畫了替代圖，這裡的三張生好之後會直接換上去。

| 檔案 | 產出的圖 | 存成 | 用在哪裡 |
|---|---|---|---|
| `panorama.md` | 1536×1024 橫圖 | `reference/scene/outdoor/panorama.png` | 池子四周一整圈的遠景（重複 6 次繞一圈） |
| `soil.md` | 1024×1024 方圖 | `reference/scene/outdoor/soil.png` | 正面的土層剖面（一直重複貼） |
| `grass.md` | 1024×1024 方圖 | `reference/scene/outdoor/grass.png` | 池子四周的草地（一直重複貼） |

## 怎麼做

1. 在 ChatGPT 上傳 `reference/character/bangui_character.png`，只當作**畫風**參考，圖裡不要出現烏龜。
2. 貼上其中一個 md 的內容，生圖。
3. 存成上表的檔名，放進 `reference/scene/outdoor/`。
4. 執行下面這行。它會自動處理接縫（ChatGPT 的圖左右接不起來）、縮小、轉成 WebP，輸出到 `assets/scene/outdoor/`：
   ```bash
   python tools/pack_scene.py outdoor
   ```
5. 遊戲網址加 `?refresh=1` 重新載入，就會看到新圖。

三張可以分開做，先做哪一張都可以。還沒生的那張，遊戲會繼續用程式畫的替代圖。

## 共同原則

- **背景要比烏龜淡**：彩度、對比都要低一點，烏龜放在上面才會跳出來。
- **跟烏龜同一種畫風**：日式繪本，柔和的手繪水彩或不透明水彩，溫暖的大地色。
- **不要有任何生物、文字、標籤**。
- **會一直重複貼的圖（三張都是）**，裡面不要有「很顯眼、只有一個」的東西，例如一棟房子、一棵特別高的樹、一顆特別大的石頭。重複貼的時候，這種東西一眼就會被看出來。
