# 戶外池場景圖

戶外池是一個**漂在天空裡的圓柱形小天地**：碗狀的池子靠在圓台正面（正面切開是土層剖面，看得到水下的烏龜），右岸是圓弧形的沙灘，後面有小溪、溪邊的石頭、濕地、矮灌木、小花。圓台外面只有天空（程式畫的，太陽和月亮會照遊戲時間劃過），不需要背景圖。
程式已經先畫了替代圖，這裡的三張生好之後會直接換上去。

| 檔案 | 產出的圖 | 存成 | 用在哪裡 |
|---|---|---|---|
| `soil.md` | 1024×1024 方圖 | `reference/scene/outdoor/soil.png` | 圓台正面和側面的土層（一直重複貼） |
| `grass.md` | 1024×1024 方圖 | `reference/scene/outdoor/grass.png` | 圓台上的草地（一直重複貼） |
| `plants.md` | 1024×1024 方圖（4×4） | `reference/scene/outdoor/plants.png` | 小花、草叢、蘆葦、香蒲、蓮花等 16 種小植物（**切圖程式等圖生好再接**） |

## 怎麼做

1. 在 ChatGPT 上傳 `reference/character/bangui_character.png`，只當作**畫風**參考，圖裡不要出現烏龜。
2. 貼上其中一個 md 的內容，生圖。
3. 存成上表的檔名，放進 `reference/scene/outdoor/`。
4. 執行下面這行。它會自動處理接縫（ChatGPT 的圖左右接不起來）、縮小、轉成 WebP，輸出到 `assets/scene/outdoor/`：
   ```bash
   python tools/pack_scene.py outdoor
   ```
5. 遊戲網址加 `?refresh=1` 重新載入，就會看到新圖。

兩張可以分開做，先做哪一張都可以。還沒生的那張，遊戲會繼續用程式畫的替代圖。

## 共同原則

- **背景要比烏龜淡**：彩度、對比都要低一點，烏龜放在上面才會跳出來。
- **跟烏龜同一種畫風**：日式繪本，柔和的手繪水彩或不透明水彩，溫暖的大地色。
- **不要有任何生物、文字、標籤**。
- **會一直重複貼的圖（兩張都是）**，裡面不要有「很顯眼、只有一個」的東西，例如一棟房子、一棵特別高的樹、一顆特別大的石頭。重複貼的時候，這種東西一眼就會被看出來。
