# 斑龜 32 動作重要度與製作優先順序

> 用途：2D／2.5D 日系繪本風斑龜養成遊戲  
> 角色：中國三線閉殼龜／斑龜（Mauremys reevesii）  
> 核心原則：以「玩家常見程度 × 生命感 × 遊戲互動價值」決定製作優先順序。


# 七、容易重複的動作要刻意區分

## `rest` vs `relax`

### `rest` — 普通休息

- 龜趴下
- 身體沉下去
- 四肢自然放鬆
- 作為一般 Idle／休息狀態

### `relax` — 心情很好時的放鬆

- 可以側躺或半趴
- 脖子伸出
- 眼睛半瞇
- 表現「吃飽、曬完太陽、被摸後」的舒服狀態

這樣兩個動作才不會功能重疊。

---

## `look` vs `observe`

### `look` — 普通張望

- 停下來
- 頭稍微轉動
- 看一下周圍
- 一般 Idle 隨機動作

### `observe` — 認真觀察

- 抬高頭
- 脖子伸長
- 明顯注意某個東西
- 適合探索或發現事件

# 九、目前製作上的關鍵建議

目前正在製作 `01～05`，這 5 個其實非常重要。

不要急著往 `06～32` 前進。

先確認：

1. **Character Identity 一致**
2. **F / R / B / L 視角一致**
3. **尾巴長度一致**
4. **背甲大小一致**
5. **頭與身體比例一致**
6. **四肢位置一致**
7. **45° 前後視角符合目前成功版本**
8. **R / L 不要過度側身**
9. **4×4 格式穩定**
10. **Python 可以穩定切成 16 張**

這 5 個如果定穩，後面的 27 個 Action 都可以直接沿用同一套 Character DNA。

# 十、整體開發優先順序

```text
                 斑龜核心
                    │
          ┌─────────┴─────────┐
          ↓                   ↓
       移動系統             Idle 系統
          │                   │
   walk / run / turn     look / rest
          │                   │
          └─────────┬─────────┘
                    ↓
               日常生活
                    │
       eat / bask / sleep
                    │
          ┌─────────┴─────────┐
          ↓                   ↓
       情緒個性             水域行為
          │                   │
 happy / wag / play      swim / dive
          │                   │
          └─────────┬─────────┘
                    ↓
                 完整龜生
```

**最重要的原則：先把「基礎行為」做穩，再用特殊動作增加個性。**

目前 `Action 01～05` 的製作順序是合理的；其中 `01 walk_a / 05 look / 14 rest / 22 eat / 09 bask / 26 swim` 會是之後遊戲中最值得反覆打磨的幾個核心動畫。
