# 連鎖互動設計（2026-09-28）

核心：**玩家碰一下世界，看看龜龜會做什麼。** 沒有任務、沒有目標，玩家不需要記得自己動過什麼。

## 四種積木

1. **物件**：水草、石頭、灌木、花叢、蘆葦、漂流木、落葉、沙地——被碰到會晃、會動，裡面可能躲著小動物
2. **訊號**（`js/signals.js`）：波紋、落水聲、沙沙聲、小動物、震動、（之後）溫暖／陰涼
3. **小動物**（`js/critters.js`）：躲在物件裡，被晃出來後自己跑、自己躲回去；跑進別的物件時那個物件也會晃
4. **龜龜的反應**：轉頭（冒泡泡）、過去看、追、吃、縮殼、不理

```
玩家的工具 ─→ 物件 ─→ 訊號 ─→ 龜龜／小動物注意到 ─→ 反應（移動）
                ↑                                      │
                └──── 小動物、龜龜移動時又碰到物件 ←──┘
```

龜龜理不理：距離、訊號強弱、好奇心（剛追完一次會懶得理，慢慢恢復）、睡著了只會被很近的大動靜嚇到。

## 游標工具（`js/tools.js`）

每一種工具是一種「滑鼠」：👁️ 看看、✋ 手手（拿、放、甩出去是丟）、👆 撥一撥、食物。
工具 × 碰到的東西 → 動作寫在 `AFFORD` 表裡，加新工具或新東西只要加一列。

## 不需要記憶的規則

- 撥動的變化都很短（幾秒到一分鐘）
- 物件裡的小動物會慢慢自己補回來（冷卻時間）
- 玩家搬動的東西留在原地，但不影響任何進度
- 沒有完成提示；日誌可以記下「今晚的小事」

## 分階段

1. ✅ 骨架：訊號、龜龜的注意力與泡泡、撥水、水草裡的小魚、撿石頭／甩出去丟
2. 陸地：灌木／花叢的蟲、蝴蝶、蜻蜓，翻石頭，放到石頭上曬背
3. 水流與夜晚：漂流木、落葉漂流與迴流、沙地挖痕與螃蟹、螢火蟲

## 連鎖的例子（都是積木組合出來的，不是寫死的劇本）

1. 撥水 → 波紋 → 龜游過去看 → 穿過水草 → 小魚竄出 → 龜追魚 → 魚躲進別叢水草（那叢也晃）
2. 丟小石子 → 落水聲 → 龜以為是食物 → 翻起泥沙 → 小蝦彈出 → 龜追蝦
3. 撥灌木 → 蟲掉出來 → 龜靠近 → 蟲爬進草叢 → 草叢晃 → 龜追進去
4. 拿起石頭 → 底下的西瓜蟲 → 龜聞到過來吃 → 放回去 → 蟲躲回去、龜守在旁邊
5. 龜放到石頭上 → 曬背 → 搬動石頭 → 龜嚇醒、嗅嗅 → 發現石頭下的蟲
6. 龜放進花叢 → 蝴蝶飛起 → 龜抬頭跟著走 → 蝴蝶停到水面 → 龜下水
7. 漂流木放到水邊 → 龜爬上去曬背 → 木頭晃、翻覆 → 龜掉進水裡開始游
8. 石頭放進小溪 → 石頭後面形成迴流 → 葉子打轉 → 龜站在溪裡咬 → 龜自己又擋出新的迴流
9. 在沙地撥 → 挖痕裡的小螃蟹 → 龜追 → 螃蟹鑽回沙裡冒泡泡
10. 搖蘆葦 → 蜻蜓點水 → 小波紋 → 接第 1 條
11. 重重放下東西 → 震動 → 附近的龜縮殼 → 探頭後靠向好朋友
12. 葉子放到溪上 → 順流漂 → 龜跟著咬 → 卡在岸邊 → 蝸牛爬上去
13. 餵飽後放到草地 → 趴著睡 → 蝴蝶停在殼上 → 撥水吵醒 → 伸懶腰
14. 晚上撥草叢 → 螢火蟲 → 停在水面的倒影 → 龜游過去看
15. （沒有玩家時）龜出門過小溪濺起水花 → 魚被嚇散 → 別的龜聽到過來
